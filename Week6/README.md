# Week 6 - Spark Architecture and Data Processing

## Objective

The objective of this assignment is to understand Spark architecture and perform efficient data processing using transformations, filtering, schema handling, optimized file formats, and data pipelines.

## Tools Used

- Python 3
- PySpark
- Apache Spark
- Jupyter Notebook
- Git & GitHub

## Topics Covered

- Spark Architecture
- Driver, Cluster Manager, and Executors
- Lazy Evaluation
- Directed Acyclic Graph (DAG)
- CSV and Parquet File Formats
- Schema Handling
- DataFrame Transformations
- Filtering and Selection
- Column Renaming and Type Casting
- Predicate Pushdown
- Data Processing Pipelines
- Transformations vs Actions
- Client Mode vs Cluster Mode
- Performance Best Practices
