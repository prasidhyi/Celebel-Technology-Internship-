# Week 6 Insights

During this assignment, I learned about the architecture of Apache Spark, including the roles of the Driver, Cluster Manager, and Executors. I understood how Spark uses Lazy Evaluation and Directed Acyclic Graphs (DAGs) to optimize execution and provide fault tolerance.

I also worked with CSV and Parquet file formats, learned how to perform schema modifications, filter datasets efficiently, add new columns, and build simple data processing pipelines. Additionally, I explored Spark performance concepts such as Predicate Pushdown and the difference between transformations and actions, helping me better understand how Spark processes large-scale data efficiently.
