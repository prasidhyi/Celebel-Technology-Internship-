# Week 3 - SQL Data Analysis using Subqueries, CTEs and Window Functions

## Objective

The objective of this assignment is to analyze sales data using SQL by applying Subqueries, Common Table Expressions (CTEs), and Window Functions. The assignment also includes solving business-related queries using a structured sales dataset.

## Tools Used

- MySQL
- VS Code
- macOS Terminal
- Python (used only for cleaning date format and importing the CSV)
- Git & GitHub

## Dataset

The Superstore dataset was imported into a raw table (`superstore_raw`). From this table, separate `customers`, `orders`, and `products` tables were created using `SELECT DISTINCT`.

## Topics Covered

- Creating and loading tables
- Subqueries
- Correlated Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()
- RANK()
- JOIN operations
- Business analysis queries
