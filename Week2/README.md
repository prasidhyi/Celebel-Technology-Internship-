# Week 2 - SQL Data Analysis Assignment

## Objective

The objective of this assignment is to practice SQL concepts by creating a relational database, loading sample data, and solving business-related queries using SQL.

## Tools Used

- MySQL
- VS Code
- Git & GitHub
- macOS Terminal

## Topics Covered

- Database Creation
- Table Creation
- Primary Keys & Foreign Keys
- Constraints
- Data Insertion
- Filtering using WHERE
- Aggregation Functions
- GROUP BY & HAVING
- Joins
- CASE Statements
- Transactions
- ACID Properties
