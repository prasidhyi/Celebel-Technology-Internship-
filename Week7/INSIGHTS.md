# Week 7 Insights

In this assignment, I learned how Delta Lake supports incremental data processing using the MERGE operation. I understood how to load data into Delta tables, clean datasets by removing duplicates and handling null values, and apply updates and inserts without replacing the entire dataset.

I also learned how Delta Lake simplifies ETL workflows by supporting ACID transactions and efficient data updates. This assignment helped me understand a practical approach to maintaining and updating large datasets in modern data engineering pipelines.
