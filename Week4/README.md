# Week 4 - Azure Cloud Fundamentals and Azure Data Factory

## Objective

The objective of this assignment is to understand Azure cloud fundamentals and build an end-to-end data pipeline using Azure Storage Account and Azure Data Factory (ADF).

## Tools Used

- Microsoft Azure
- Azure Storage Account
- Azure Blob Storage
- Azure Data Factory (ADF)
- Git & GitHub

## Tasks Performed

- Created an Azure Resource Group
- Created an Azure Storage Account
- Created a Blob Container
- Uploaded the Superstore CSV dataset
- Created Azure Data Factory
- Configured a Linked Service to Azure Blob Storage
- Created Source and Destination datasets
- Used Get Metadata activity to retrieve file information
- Built a Copy Data pipeline
- Executed the pipeline successfully
- Assigned IAM roles to allow Azure Data Factory to access Blob Storage

## Azure Services Used

- Resource Group
- Storage Account
- Blob Container
- Azure Data Factory
- Azure IAM (Access Control)
